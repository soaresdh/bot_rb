# PonsBot · visualização pública

Interface visual do painel, sem histórico de operações, posições abertas, carteiras, tokens, saldos, estratégias, parâmetros ou controles de negociação. Os indicadores não recebem dados reais. Nenhum servidor do bot é conectado ou exposto.

GitHub Pages: Settings > Pages > Build and deployment > Source: GitHub Actions. O workflow publica apenas index.html, painel.css, visual.js e .nojekyll.
